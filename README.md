# Media Pembelajaran Interaktif IPS: Literasi Finansial & Pengenalan Rupiah (`ifp-intan`)

Media Pembelajaran Interaktif Standalone 1-File HTML5 bergenre Game Kuis Edukasi IPS (*Ilmu Pengetahuan Sosial*) untuk Kurikulum Merdeka Fase D (SMP Kelas 7, 8, dan 9).

## 📌 Detail Spesifikasi & Fitur

- **Folder Proyek:** `ifp-intan`
- **File Utama:** `index.html` (100% Single-File HTML5 Standalone tanpa dependensi server/backend)
- **Mata Pelajaran:** IPS (Ilmu Pengetahuan Sosial) & Ekonomi Kreatif
- **Topik / Materi Pokok:** Pengenalan Rupiah TE 2022, Unsur Pengaman 3D Rupiah, Literasi Finansial, Manajemen Anggaran 50/30/20, Inflasi & Daya Beli, QRIS & Pembayaran Digital, Legalitas Investasi OJK vs Skema Ponzi.
- **Jumlah Soal HOTS:** **20 Soal Pilihan Ganda HOTS (Tingkat C4 Analisis – C6 Evaluasi)**.
- **Pilihan Jawaban Pengecoh (Quality Distractors):** Setiap soal memuat 1 Jawaban Benar + 3 Pilihan Jawaban Pengecoh yang sangat mirip, logis, dan menguji kedalaman konsep.
- **Randomisasi & Distribusi Kunci Jawaban:** Teracak dengan rasio seimbang (25% A, 25% B, 25% C, 25% D).
- **Target Tampilan:** Layar Sentuh Interaktif **Interactive Flat Panel (IFP 4K)**, Laptop, Tablet, & Smartphone.

## 🚀 Cara Menjalankan

1. Buka file `index.html` secara langsung di browser apa saja (Chrome, Edge, Firefox, Safari).
2. Tidak memerlukan instalasi Node.js, server, atau koneksi internet.

## 📝 Hak Cipta & Penggunaan

Didesain untuk fasilitasi pembelajaran aktif di depan kelas menggunakan layar sentuh interaktif IFP 4K.
